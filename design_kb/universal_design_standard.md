# 汎用デザイン標準（ジャンル非依存・全アカ共通ベース）

> どのジャンルでも効く「バズ/保存される投稿の共通法則」。プロ分析（SAKIYOMI/12万人P みのる/構成note 等）が
> 何百ものバズアカをリバースエンジニアした共通項を集約。**全アカがこのベースを継承し、ジャンルでは“可変レイヤー”だけ変える**。

## A. 不変の原則（全ジャンル共通・数値つき）

### 1. 構成＝「認知される型」を毎回固定
- 流れ: **フック(1枚目) → 導入/共感(2枚目) → 中身(3〜N枚・1枚1メッセージ) → CTA(最終枚)**
- 毎回同じ型にすることで「このアカの投稿だ」と**認知される型**が生まれる（一貫性＝伸びる前提）
- 出典: 構成note / カプセル(アルゴリズム)

### 2. 1枚目が最重要（発見タブ流入・最初の2秒）
- 目的: **スクロールを止める／続きを見たくさせる**
- 文字数: **15〜20字以内**（短いほど良い・流し見で一瞬で分かる）
- 型: 数字 / 「○○な人へ」名指し / 問いかけ / **損失回避（知らなきゃ損）**
- 1枚目が弱いと全部スルー → ここに最大の力をかける

### 3. 中身スライド
- **1スライド＝1メッセージ**
- 見出し＋**2行以内**の簡潔解説。図解/アイコンで視覚化
- 2枚目は「導入/共感」（私も失敗した等）で“読む理由”を作る

### 4. 保存される3条件（アルゴリズムは保存・シェア・滞在を重視＝いいねより上）
- **実用性**（後で見返したくなる）
- **見やすさ**（情報が整理・スッキリ）
- **導線**（保存・フォロー・プロフへ誘導）

### 5. デザイン規律（見やすさ＞オシャレ）
- **色は3色以下**（75:20:5）・原色蛍光NG・低彩度でプロっぽく
- **余白多め**（文字3:余白7）・詰め込まない
- **フォント2種**（見出し＋本文）・**ジャンプ率1.5倍以上**
- 視認性を最優先（映えより読みやすさ）

### 6. CTA（最終枚）
- 「保存がおすすめ」「フォローして」「プロフィールへ」を明示＝行動喚起が保存理由になる

## B. 可変レイヤー（ジャンルで差し替える部分だけ）
→ 詳細は [[genre_design_map]]
- **テーマカラーのムード**（青=誠実 / 橙=情熱・食欲 / 緑=優しさ・健康 / くすみ=癒し 等）
- **フォント系統**（名言=明朝 / お金仕事=角ゴシック / 女性=丸ゴシック / 和=筆）
- **コピーの温度**（煽り強め↔やさしい）と具体テーマ

## C. エンジンへの焼き込み（実装方針）
- 上のA（不変）は **render系の初期値**として固定（cover/quote/tip/pair/cta・3色・余白・2フォント・CTAは既に準拠）
- B（可変）だけ `style_presets.json` ＋ アカの design_system で上書き
- **現状ギャップ**: 我々のカルーセルは cover→中身→cta で「2枚目=導入/共感」が無い。tips/お金系は **2枚目に共感/前提スライドを足す**と保存率が上がる余地あり（任意の構成拡張）
