# サムネ用フックコピー型（指を止めるタイトルの型）

> サムネ生成時に「このタイトルなら止まる」を提案するための型。出典: ほんわか/LEAD ONE/SAKIYOMI/Instagramラボ。
> カルーセル1枚目とも共通だが、サムネは**さらに短く・強く**。

## 鉄則
- **ベース＋フック**で組む（ベース=主題／フック=惹く修飾）
- **10〜13字**目安・強調は**1〜2語**（emで色を変える）
- **数字を1つ**（奇数=3/5/7が目を引く）／固有名詞で具体性
- ⚠️**中身と一致必須**：動画/投稿に無い言葉・過度な煽りはNG。クリック後に離脱→アルゴリズム逆効果・スパム判定（[LEAD ONE](https://lead-one.info/youtube/2464/)）
- ⚠️ 「神」「最強」連発・効果断定はしない（全アカ共通NG）

## 8つの型（例つき）
| 型 | 例 |
|---|---|
| ①結果提示 | 「AIに丸投げしたら**全部できた**」「3日やった**結果**」 |
| ②数字 | 「見直す固定費**8つ**」「**年5万円**浮いた」 |
| ③損失回避 | 「**知らないと損**する〇〇」「やってはいけない〇〇」 |
| ④逆説・常識破壊 | 「**実は**〇〇は要らない」「〇〇**しない**ほうがいい」 |
| ⑤問いかけ・図星 | 「〇〇**してない？**」「まだ〇〇で消耗してる？」 |
| ⑥Before→After | 「〇〇**→**〇〇」（ペア型と相性◎） |
| ⑦ターゲット名指し | 「**〇〇な人へ**」「初心者**必見**」 |
| ⑧ギャップ・意外 | 「**まさかの**〇〇」「99%が知らない〇〇」 |

## 媒体別の効き方
- **YouTube**：①結果提示・②数字・④逆説が強い。煽れるが**中身一致**が絶対。style=night/mono
- **IGリール表紙**：お得感・情報まとめ・⑦名指し。10字・大きく。style=calm/pastel/mono
- **note見出し**：具体ベネフィット＋数字。誇張より「読めば得」。style=mono/calm

## スタイル対応（emで強調する語）
- 数字・結果・ベネフィットの**核1語をem:true**にして accent 色で立てる（例：`{text:"全部できた",em:true}`）
